# REQ-0003: Tenets and learning outcomes stay aligned with *The Atomic Human* takeaways

## Description

The exec course must have a stable set of tenets (WHY) and learning outcomes (WHAT) that remain aligned with the book’s core takeaways (uncertainty, trust/accountability, intent/incentives, manipulation/System Zero, human–tool/agent co-adaptation).

This guards against drift where the course accumulates extra content but loses coherence, and it gives maintainers a clear basis for deciding what to add, remove, or rename.

## Acceptance Criteria

- [ ] Each tenet in `tenets/execed/` has an explicit linkage to the book takeaways (and is reviewed on its stated cadence).
- [ ] Course lectures/modules each declare which tenets and learning outcomes they serve (at least in a mapping document or maintained index).
- [ ] When lectures are renamed/reordered, the tenet/outcome coverage remains explicit and checkable (no “silent loss” of key themes).

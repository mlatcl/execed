# REQ-0002: Course supports a core exec pathway and an optional chapter-aligned series

## Description

The course should support two valid delivery modes without fragmenting content:

- a **core executive pathway** (approximately 6–8 lectures/modules) that is outcome-driven and time-efficient
- an **optional extended series** (intro + one lecture per *The Atomic Human* chapter) for a seminar/deeper-dive format

Both should share a consistent “spine” of concepts and reuse the same underlying materials where possible (snippets, examples, diagrams), with the difference being depth and pacing.

## Acceptance Criteria

- [ ] A documented mapping exists from executive learning outcomes → (core pathway modules) and → (extended chapter-aligned modules).
- [ ] The two pathways are consistent in terminology and framing (no contradictory definitions or duplicated-but-divergent narratives).
- [ ] The course can be delivered using either pathway without requiring separate, incompatible content repositories.
